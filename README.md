# Ringside 32

3D-boxningsspel i 32-bitarsstil för Android (PWA). Spela: https://cruzin4bruzinrl-code.github.io/ringside32/

- `index.html` – hela spelet i en fil
- `sw.js` – service worker: hämtar alltid senaste versionen, fungerar offline
- Versionsnumret i menyn (`id="ver"`) höjs vid varje ändring; appen laddar då om sig själv automatiskt.
